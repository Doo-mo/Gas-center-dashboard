# PROJECT_CONTEXT.md — 가스연료기술센터 대시보드

> 이 문서는 Claude 이관을 위한 프로젝트 맥락 요약입니다.

---

## 프로젝트 목적

**대체연료본부 가스연료기술센터**의 사업 현황을 한눈에 파악할 수 있도록,  
엑셀 데이터를 **브라우저 전용 대시보드**로 시각화하는 도구입니다.

- 별도 서버·인프라 없이 GitHub Pages로 배포
- 엑셀 파일은 브라우저 안에서만 처리 (서버 전송 없음)
- 보고서 작성·회의 발표용 PNG/PDF 내보내기 지원

## 사용자

- 가스연료기술센터 내부 담당자 (비개발자 포함)
- 엑셀 파일을 직접 관리하는 행정·연구 담당자
- 주기적으로 KPI 보고가 필요한 팀장·센터장급

## 주요 기능 요구사항

| 기능 | 설명 |
|------|------|
| 엑셀 업로드 | 드래그앤드롭 + 파일 선택 버튼 |
| KPI 카드 | 센터 전체 + 3개 팀(전산/탄소/극저온)별 실적·항목별 내역 |
| 목표금액·달성률 | `분기별 보고` 시트에서 자동 파싱 (없으면 숨김) |
| 팀 비율 도넛 차트 | 3개 팀 비율 + 달성률(또는 합계) 중앙 표시 |
| 항목 비율 도넛 차트 | 국가연구개발/수탁용역/시험인증 비율 |
| 팀별 누적 막대 차트 | 팀별 항목 금액 누적 표시 |
| 전체 목록 표 | 시트별 탭, 합계 행 상단 고정(sticky) |
| 화면 캡처 | KPI + 차트 영역만 PNG로 저장 |
| PDF 내보내기 | 가로 A4, KPI + 차트 영역만 |

## 배포 URL

`https://doo-mo.github.io/Gas-center-dashboard/`  
(GitHub Pages, `main` 브랜치 루트 기준)

## 기술 제약

- 빌드 도구 없음, 패키지 관리자 없음
- 모든 외부 의존성은 jsDelivr CDN (`https://cdn.jsdelivr.net`) 경유
- Internet Explorer 미지원 (ES6+ 문법 사용)

## 알 수 없는 사항 (확인 필요)

- 실제 업무 엑셀 파일의 정확한 컬럼 구조는 공개 저장소에 없으므로 직접 확인 필요
- 목표금액 파싱 로직이 실제 파일의 다양한 레이아웃을 모두 커버하는지 미검증
