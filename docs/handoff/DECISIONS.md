## 확인된 결정

### 1. 순수 정적 웹 앱 (빌드 없음)
- **결정**: HTML + JavaScript만 사용, 빌드·패키지 관리 도구 없음
- **이유**: 비개발자도 바로 열 수 있는 단순성, GitHub Pages 무료 배포
- **영향**: 모든 의존성은 CDN 경유; 번들링·트리쉐이킹 없음

### 2. 브라우저 전용 데이터 처리
- **결정**: 업로드된 엑셀 데이터를 서버에 전송하지 않고 `FileReader` + SheetJS로 클라이언트에서만 처리
- **이유**: 내부 업무 데이터(연구비, 계약금액 등) 보안 요건
- **영향**: 서버 사이드 로직 불필요; 오프라인 가능(CDN 캐시 시)

### 3. 팀 배분: 시험인증 → 전량 극저온
- **결정**: `시험인증` 시트의 실적은 팀 구분 없이 전부 극저온 팀으로 집계
- **이유**: 실제 조직 업무 구조 반영 (README 명시)

### 4. 합계 행 자동 감지·제외
- **결정**: 칸 내용 전체가 "합계/총계/소계"(공백 무시, 예: `합 계`, `소계(A+B)`)인 행만 제외 후 직접 재합산
- **이유**: 엑셀에 이미 있는 합계 행을 중복 집계하지 않기 위함
- **변경 (2026-11-01, PR #3)**: 이전에는 줄 전체에 해당 글자가 들어 있기만 해도 제외해서, 과제명·비고에 "통합계측", "총계약금액" 등이 있는 행이 집계에서 빠졌음

### 5. 캡처/PDF 영역: KPI + 차트만
- **결정**: `id="captureArea"` 영역(KPI + 차트 3개)만 PNG/PDF로 내보내고 하단 전체 목록 표는 제외
- **이유**: 보고서·발표 자료로 활용할 때 간결한 요약만 필요

### 6. 차트 색상 분리
- **결정**: 팀을 나타내는 색(주황/초록/파랑)과 사업 항목을 나타내는 색(인디고/로즈/틸)을 다르게 설정
- **이유**: 같은 화면에 두 종류의 도넛 차트가 표시될 때 혼동 방지

### 7. 팀 미지정 행은 자동 배정하지 않고 안내만 표시 (2026-11-01)
- **결정**: 팀(담당팀)이 비었거나 전산/탄소/극저온이 아닌 행은 센터 합계에만 넣고, 화면에 건수·금액·목록을 노란 안내로 표시
- **이유**: 빈 담당팀을 특정 팀(예: 전산)으로 자동 처리하면, 다른 팀 용역이 생겼을 때 조용히 틀린 숫자가 나옴. 엑셀을 고치도록 알리는 쪽을 선택

### 8. SheetJS는 공식 CDN에서 로드 (2026-11-01)
- **결정**: SheetJS 0.20.3을 `cdn.sheetjs.com`에서 로드 (나머지 라이브러리는 jsDelivr 유지)
- **이유**: 0.18.5의 알려진 취약점(CVE-2023-30533, CVE-2024-22363) 수정 버전이 npm/jsDelivr에는 없음
- **영향**: 이용 환경에서 `cdn.sheetjs.com` 접속이 가능해야 함 (업무 PC에서 확인됨)

### 9. 관리자 요청은 구글 폼 + 텔레그램 알림 (2026-11-01)
- **결정**: 대시보드에는 구글 폼 링크 버튼만 두고, 알림은 폼에 연결된 Apps Script가 텔레그램 봇으로 전송
- **이유**: 서버 없는 정적 사이트 유지, 공개 사이트에 관리자 이메일 노출 방지, 이용자는 계정 없이 요청 가능
- **영향**: 업로드한 엑셀 데이터는 폼으로 전송되지 않음. 봇 토큰은 Apps Script 스크립트 속성에만 보관

### 10. 변경사항 확인은 "처음 공유한 원본"과 비교 (2026-11-04)
- **결정**: 회신본을 직전 취합본이 아니라 처음 공유한 원본과 비교하고, 팀 선택은 "보여줄 범위"로 사용. 선택 팀 밖의 변경은 "다른 팀 영역 변경"으로 따로 경고
- **이유**: 직전 취합본과 비교하면 먼저 반영한 팀의 수정이 다음 팀 회신본에서 계속 "되돌림"으로 보임. 원본 기준이면 각 회신본에는 그 팀의 수정만 남음 (취합 순서 무관)
- **행 맞추기**: 실제 파일에서 관리번호는 절반만 채워져 있고 과제명·순번도 중복이 있어 단일 키로 맞출 수 없음 → 과제명 유사도(60%) + 나머지 칸 일치율(40%)로 점수를 매기고 순서를 지키며 짝지음(동적 계획법). 남은 행끼리 아주 비슷하면(0.8 이상) "위치 이동"으로 처리
- **비교 값**: 표시 글자가 아닌 실제 값(raw) 기준. `순번`·`연번`은 제외
- **내려받기 없음**: 화면 표시만. 바뀐 칸을 색칠한 엑셀은 서식 보존을 위해 별도 라이브러리(ExcelJS)가 필요해 보류
