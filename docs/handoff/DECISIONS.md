## 확인된 결정

### 1. 순수 정적 웹 앱 (빌드 없음)
- **결정**: HTML + JavaScript만 사용, 빌드·패키지 관리 도구 없음
- **이유**: 비개발자도 바로 열 수 있는 단순성, GitHub Pages 무료 배포
- **영향**: 모든 의존성은 CDN 경유; 번들링·트리쉐이킹 없음

### 2. 브라우저 전용 데이터 처리
- **결정**: 업로드된 엑셀 데이터를 서버에 전송하지 않고 `FileReader` + SheetJS로 클라이언트에서만 처리
- **이유**: 내부 업무 데이터(연구비, 계약금액 등) 보안 요건
- **영향**: 서버 사이드 로직 불필요; 오프라인 가능(CDN 캐시 시)

### 3. 팀 배분: 시험인증 → 전량 극저온
- **결정**: `시험인증` 시트의 실적은 팀 구분 없이 전부 극저온 팀으로 집계
- **이유**: 실제 조직 업무 구조 반영 (README 명시)

### 4. 합계 행 자동 감지·제외
- **결정**: "합계/총계/소계" 키워드 포함 행은 데이터에서 제외 후 직접 재합산
- **이유**: 엑셀에 이미 있는 합계 행을 중복 집계하지 않기 위함

### 5. 캡처/PDF 영역: KPI + 차트만
- **결정**: `id="captureArea"` 영역(KPI + 차트 3개)만 PNG/PDF로 내보내고 하단 전체 목록 표는 제외
- **이유**: 보고서·발표 자료로 활용할 때 간결한 요약만 필요

### 6. 차트 색상 분리
- **결정**: 팀을 나타내는 색(주황/초록/파랑)과 사업 항목을 나타내는 색(인디고/로즈/틸)을 다르게 설정
- **이유**: 같은 화면에 두 종류의 도넛 차트가 표시될 때 혼동 방지
